## Full Assembly Process
This procedure doesn't include every little detail, like how we made the crossovers, how we tested them, etc. but it goes over the main stuff. This was also written with the surround speakers in mind, so the exact details might vary slightly with the other speakers.
1. My dad did most of the designing using solidworks, but he talked me through some of the choices he made, particularly as it relates to the way that you have to design parts so that they're easier to assemble, and all fit together properly.
2. He showed me how to convert the solidworks file into a toolpath program, then into a CAM program to be able to create the parts on a CNC machine.
3. We used the program we created to cut out the parts for the speaker boxes.
4. We separated out, then flesh trimmed off all of the extra material from the parts, and used a metal brush to clean them up.
5. We built each box, starting by using tape so that it's easy to keep the parts lined up while we're assembling it, then we used glue and connected each part into the fitted locations that we designed on each one.
6. The parts fit together just fine, and weren't loose, so rather than using clamps we just used more tape, but this time not to make things easier to line up. This time we used it to enforce the parts together.
7. We scraped any excess glue off, then after a while we removed the tape, and the structure of the speaker boxes were complete.
8. Next we made sure that all of the parts were fit together how they were supposed to be, and that all of the excess glue residue was gone.
9. We performed an initial sanding around the box using an orbital sander.
10. Then we went through with a finer grit and manually sanded the speaker boxes over to make them properly rounded and mostly smooth.
11. Next we performed a similar set of processes for making the rings which are to fit around the driver later on, as well as any other pieces we were waiting to attach, we just didn't need any tape or glue.
12. Next we painted each part and box in 3 different stages, giving each coat of paint time to dry before the next one.
13. Between each new coat we did some final sanding in different areas where needed, particularly to round out the edges of the boxes.
14. We used a thin rubber material around the inner edges of the rings and boxes to help keep the rings in place when we place them onto the boxes.
15. We drilled in sets of brackets on each speaker box to later be used to affix them to the wall.
16. We trimmed, then ran a couple of wires through each speaker box to later be used to connect the circut to the driver, and to connect the driver to the home system.
17. We constructed simple circuts, and used soder to connect all of the wires together.
18. Then we placed each driver into a speaker box, and tested them for airleaks and other possible issues.
19. After the speakers were all properly functioning, we cleaned them up, and applied a felt cover to the front of each one.
20. We wrapped and packaged each one to prevent transport damage.
21. Then we loaded them into a truck with cushioning material and tarps surrounding them, and drove them to their destination
